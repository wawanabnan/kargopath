# KargoPath Documentation Hub (SSOT)

Dokumen ini adalah pintu masuk tunggal dokumentasi proyek agar AI agent dan developer manusia tidak bingung.

## Read Order (Wajib)
1. `docs/handoff_checkpoint.md` - status saat ini, progress, dan next action.
2. `docs/business_rules.md` - aturan bisnis operasional yang harus dipatuhi sistem.
3. `docs/decision_log.md` - keputusan arsitektur/desain dan alasannya.
4. `PRD.md` - visi produk, modul, dan roadmap level tinggi.

## Document Governance
- Aturan bisnis HARUS ditulis di `docs/business_rules.md`.
- Keputusan arsitektur HARUS ditulis di `docs/decision_log.md`.
- Status eksekusi/progress HARUS ditulis di `docs/handoff_checkpoint.md`.
- `PRD.md` tetap high-level, bukan tempat aturan operasional detail.

## Archive Policy
File berikut bersifat referensi historis, bukan sumber kebenaran utama:
- `docs/request_quotation_redesign_plan.md`
- `docs/implementation_plan_multi_tenant.md`
- `plans/*.md`

Gunakan file arsip hanya untuk konteks lama. Jika ada konflik isi, ikuti urutan dokumen pada "Read Order".
